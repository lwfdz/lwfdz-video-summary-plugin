# 隐私说明

“视频总结”第一版会向 B 站公开接口请求用户提交的视频链接、公开元数据和公开字幕。

- 默认不会下载或保存视频、音频文件。
- 未配置 `OPENAI_API_KEY` 时，字幕材料由连接该 MCP 应用的模型处理。
- 配置 `OPENAI_API_KEY` 后，字幕文本会发送至 OpenAI API 生成服务端总结。
- 用户明确保存总结时，条目会写入部署实例的 `DATA_DIR/library.json`。
- `BILIBILI_COOKIE` 仅用于访问部署者本人有权访问的字幕，不应提交到公开仓库。
- 本项目不会出售个人数据。

公开部署前，部署者应根据实际域名、日志、数据库、第三方服务和用户群体补充正式隐私政策。
